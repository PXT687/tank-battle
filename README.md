# 坦克大战 · Tank Battle

一个纯 HTML / CSS / JavaScript 实现的经典坦克大战游戏，单文件即可运行，无需任何依赖或构建步骤。

## 快速开始

直接用浏览器打开 `index.html` 即可游玩，也可以部署到任意静态托管服务。

在线试玩（GitHub Pages）：https://pxt687.github.io/tank-battle/

## 操作方式

| 操作 | 按键 |
| --- | --- |
| 移动 | 方向键 或 `W A S D` |
| 开火 | `空格` 或 `J` |
| 开始 / 重新开始 | 任意键 / 点击 / `R` |

触屏设备会自动显示虚拟方向键和开火按钮。

## 玩法

- 控制坦克消灭一波又一波的敌军坦克。
- **守住底部的基地（★）**——基地被摧毁则游戏结束。
- 砖块墙可被子弹摧毁，钢块墙不可摧毁。
- 每消灭一个敌人得 100 分，清空一波额外奖励 500 分。
- 道具：`S` 护盾、`R` 连射、`♥` 加命。

## 特性

- 敌方坦克 AI（自动移动与射击）
- 可摧毁砖墙 / 不可摧毁钢墙
- 波次递增难度（敌人数量、速度、射速逐波提升）
- 三种随机道具掉落
- 粒子爆炸特效
- Web Audio 合成的音效（无外部音频文件）
- 键盘 + 触屏双重操控
- 单文件、离线可玩、零依赖

## 技术栈

- HTML5 Canvas 2D
- 原生 JavaScript（无框架）
- Web Audio API
